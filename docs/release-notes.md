# Sandboxie MCP 1.0.0

Local stdio MCP integration for Sandboxie Plus 1.18.5 on Windows 11 x64, with 43 tools and three resources.

The release manages sandbox definitions, configuration, templates, resource/network/program rules, processes, files, native snapshots and versioned archives. It includes diagnostics, native component/image controls, user-owned access policies and English/Russian result messages.

The Windows package contains a self-contained executable, configuration profiles, documentation, dependency inventory and notices. Extract it and follow [the README](../README.md) to connect Codex. Core workflows were exercised without a Supporter Certificate. Encrypted images remain entitlement-dependent and lack live coverage in the tested installation.

See [validation](validation.md) for executed checks and environment limits, and [compatibility](compatibility.md) for the public behavior boundaries.
